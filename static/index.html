Dated class-session timeline

Inspect every date before the exam and see exactly why it was counted or excluded.

☷
The timeline is calculated by the authenticated server-side schedule engine using subject-specific class overrides, holidays/no-class dates, active slot codes, weekday substitutions, and configured weekly mappings. The exam date itself is excluded. This is an explainability view, not an official VIT timetable decoder.

Dates are evaluated from today up to, but not including, the exam date. If a date has no active slot entry, BunkSafe falls back to its configured weekday mapping unless another calendar event overrides it.
